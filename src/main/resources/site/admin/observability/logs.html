Start time: specifies the start time of the search window. On page load, it's automatically set to the start of the current day. Clearing this field will cause the search to fetch 24h behind End time.

End time: specifies the end time of the search window. On page load, it's automatically set to the end of the current day. Clearing this field will cause the search to fetch 24h past Start time.

Severities: specifies the log severities to be included in the search. To include multiple, simply separate the names with a comma. Clearing this field will cause the search to ignore this filter.

Thread pattern: specifies the thread's name pattern. Clearing this field will cause the search to ignore this filter.

Logger pattern: specifies the logger's name pattern. Clearing this field will cause the search to ignore this filter.

Message pattern: specifies the message pattern. Clearing this field will cause the search to ignore this filter.

Exception class pattern: specifies the exception class pattern. Clearing this field will cause the search to ignore this filter.
