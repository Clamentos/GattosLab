Start time: specify the start time of the window. On page load, it's automatically set to the start of the current day. Clearing this field will cause the search to fetch 24h behind End time.

End time: specify the end time of the window. On page load, it's automatically set to the end of the current day. Clearing this field will cause the search to fetch 24h past Start time.

Only others: specify if bogus paths (non existent / unknown) should be included or not in the search filter.

Path pattern: specify the path pattern. Clearing this field will cause the search to ignore this filter.

HTTP Statuses: specify the response statuses to be included in the search. To specify multiple, simply separate the values with a comma (no spaces). Clearing this field will cause the search to ignore this filter.

User agent pattern: specify the user agent's pattern. Clearing this field will cause the search to ignore this filter.
