Home > Admin > System metrics

Start time: specifies the start time of the search window. On page load, it's automatically set to the start of the current day. Clearing this field will cause the search to fetch 24h behind End time.

End time: specifies the end time of the search window. On page load, it's automatically set to the end of the current day. Clearing this field will cause the search to fetch 24h past Start time.

Resolution: specifies the resolution of the charts in seconds. Clearing this field will cause the charts to default to 10 minutes (600 seconds).
